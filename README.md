# PDF RAG Chatbot

PDF document search application using Python, Hugging Face and FAISS.

## Features
- PDF Upload
- PDF Text Extraction
- Text Chunking
- Hugging Face Embeddings
- FAISS Vector Database
- Semantic Search

## Technologies
- Python
- Streamlit
- PyPDF
- Sentence Transformers
- FAISS
- LangChain

## Architecture
PDF ? Text Extraction ? Chunking ? Embeddings ? FAISS ? Semantic Search

## Run Application

pip install -r requirements.txt

streamlit run app.py
